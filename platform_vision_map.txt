--------------------------------------------------------------------------------
1. EXECUTIVE SUMMARY & PLATFORM MISSION
--------------------------------------------------------------------------------
Hyrlink is an all-in-one software platform that helps job seekers stand out and 
enables recruiters to actively source matches instantly. By decoupling 
heavy AI evaluations from a lightweight, concurrent Go backend, the system 
scales to thousands of concurrent users while leveraging a custom-trained SLM.

--------------------------------------------------------------------------------
2. B2C CANDIDATE PORTAL WORKFLOW
--------------------------------------------------------------------------------
A. User Onboarding & Identity
   - SSO Login: OAuth integration (Google, Apple, Facebook, etc.) via Supabase.
   - User Tagging: Every user is assigned a UUID; all uploads, configurations, 
     and evaluations are tagged with this UUID.
   - Profile Questionnaire: Captures candidate experience, career goals, writing 
     style, cadence, and personality traits.

B. Resume Strategy
   - Backup Resume: The original uploaded PDF/Docx is safely backed up in storage.
   - Optimized Resumes: For every job description the user provides, the system 
     generates a tailored, high-impact resume optimized for that description.
   - Recruiter Callback Scorer: Runs candidate_evaluator.py (fine-tuned SLM) 
     against JDs to output the likelihood of a recruiter calling them.

C. B2C Monetization Tiers
   - Free Tier: Profile setup, original resume parser, and basic matching score.
   - Pro Tier: Standard matching + detailed STAR-method role-fit guidance.
   - Elite Tier: All features + a personal chatbot trained on their background.

--------------------------------------------------------------------------------
3. B2B ENTERPRISE PORTAL WORKFLOW
--------------------------------------------------------------------------------
A. Recruiter Workspace
   - Job Dashboard: Recruiters can post open roles and detail requirements.
   - Active Sourcing: The system scans the entire user directory and surfaces 
     matching candidates (resumes + personalities) even if they haven't applied.
   - Priority Placement: Paying B2C candidates (Elite/Pro) get top priority.
   - Candidate Bot Chats: Recruiters can chat with a candidate's personal chatbot 
     to preview their style/fit before making a phone call.

B. B2B Monetization Models
   - Large Organizations: Flat rate per seat, unlimited candidate matches.
   - Staffing Agencies: Flat rate per seat OR Pay-per-Candidate (approx $2-5 per 
     set number of LLM tokens consumed).

5. DATABASE SCHEMA BLUEPRINT (Supabase/PostgreSQL)
--------------------------------------------------------------------------------
- PROFILES TABLE:
  Stores UUIDs, email, names, tier (free/pro/elite), personality indicators,
  and onboarding questionnaire responses.
  
- RESUMES TABLE:
  Stores references to the raw original PDF in Supabase Storage, optimized 
  resume variations, and vector embeddings (pgvector) to support search.
  
- JOB POSTINGS TABLE:
  Stores job descriptions, keywords, recruiter UUID, and required skills.
  
- EVALUATIONS TABLE:
  Stores final scores (overall score, skill match, experience, education, impact), 
  verdicts, recommendations, and execution metrics.

--------------------------------------------------------------------------------
6. SCALING THE ELITE TIER CANDIDATE CHATBOTS
--------------------------------------------------------------------------------
To support thousands of individual candidate chatbots without the impossible cost
of fine-tuning individual models:
1. Candidate facts, resume text, and style preferences are split into chunks.
2. Embeddings are generated and saved under their UUID in Supabase (pgvector).
3. When a recruiter opens a chat, the Go server uses the recruiter's message 
   to perform a similarity search against the candidate's vector database.
4. The Go server builds a prompt: System Prompt + Context Facts + Cadence Rules.
5. The LLM processes this dynamically, speaking precisely in the voice, tone, 
   and background of the candidate.

7. PHASED IMPLEMENTATION PLAN
--------------------------------------------------------------------------------
PHASE 1: B2C MVP Setup
  - Initialize Supabase backend & PostgreSQL schemas.
  - Set up Next.js candidate onboarding pages.
  - Implement Go backend APIs (SSO check, resume upload, async evaluation).
  - Launch candidate builder and evaluator score engine.

PHASE 2: B2B Recruiting & Active Search
  - Create recruiter dashboard UI.
  - Code the pgvector similarity search in Go to find matching candidates.
  - Match-rank applicants and set up billing gates.

PHASE 3: Candidate Chatbots & Scale
  - Deploy vLLM server to cloud GPU (RunPod/GCP VM) to host the custom SLM.
  - Build the RAG/vector chat retrieval pipelines for the Elite chatbots.
  - Launch subscription models for candidate & enterprise seats.
